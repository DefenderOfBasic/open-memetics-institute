# Code of Conduct

_Anyone doing open memetics abides by the code described on this page._

1. If you gain predictive power over an entity, you must disclose this to the entity 

For example, if I am part of your sociology study/survey, and you learn something about me / my cohort, you need to then communicate that back to me. 

If you do memetic analysis of tpot, you have to tell tpot. If you do this, you can keep doing it. If they stop being able to understand what you're learning about them, then the project goes into dangerous territory.
